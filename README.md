# Property TV Management System

## Overview
A database project designed to manage hotel properties, TV equipment, and technical support tickets.

## Features
- Property Management
- Equipment Management
- Ticket Management

## Database Design
Entities:
- Property
- Equipment
- Ticket

Relationships:
- One Property can have many Equipment records.
- One Property can have many Ticket records.

## Technologies Used
- Oracle SQL
- SQL Plus
- ER Diagram

## SQL Concepts Demonstrated
- CREATE TABLE
- INSERT INTO
- SELECT Statements
- WHERE Conditions
- Logical Operators
- Single Row Functions
- Multiple Row Functions
- UNION
- UNION ALL
- INTERSECT
- MINUS
